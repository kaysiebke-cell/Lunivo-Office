# Lunivo-Office

Ein lokales Schreibprogramm mit fester Schreibhilfe — offline, ohne Konto.

Kurzüberblick

- Kontextsensitive Schreibhilfe (Seitenleiste)
- Prüfen (F7), Vorlesen (F4), Wortvorhersage, phonetische Suche
- Export: .odt, .docx, .pdf, .html, .txt, epub
