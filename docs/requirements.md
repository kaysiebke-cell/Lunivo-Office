# Systemanforderungen & Installation

Empfohlene Pakete (Debian/Ubuntu)

    sudo apt install python3-gi gir1.2-webkit2-4.1

Optionale Komponenten

- LibreOffice (für DOCX/PDF-Funktionen) — ca. 700 MB (optional; das Programm bringt einen eigenen LibreOffice‑Motor mit)
- LanguageTool (für tiefere Prüfung) — ca. 400 MB (optional)
- Piper (offline TTS) + Stimmen — ca. 90 MB (optional)
- Schriften für bessere Lesbarkeit (OpenDyslexic, Lexend, Atkinson) — ca. 4 MB (optional)

Installation von Zusatzdateien (Beispiele)

- Stimmen:

    ./stimme-holen.sh

- Schriften:

    ./schrift-holen.sh

Hinweise zu KI‑Funktionen

Lunivo‑Office bietet optionale KI‑Integrationen (z. B. Ollama lokal oder Claude in der Cloud). KI‑Nutzung erfordert jeweils Konfiguration in den Einstellungen (API‑Schlüssel, Modellwahl).
