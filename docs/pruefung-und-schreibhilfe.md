# Prüfsystem & Schreibhilfe

Die Schreibhilfe arbeitet regelbasiert und priorisiert weniger falschen Alarm über Vollständigkeit. Wichtige Eigenschaften:

- Kategorien von Funden:
  - Sicher falsch — automatische Korrekturvorschläge sinnvoll
  - Kommt drauf an — z. B. Komma, das/dass; Entscheidung durch Nutzer
  - Zum Nachdenken — stilistische Hinweise, keine automatische Änderung

- Jede Meldung legt eine Karte in der Seitenleiste an. Nutzer können *Zeigen*, *Ändern* oder weiter kommentieren.

- Phonetische Suche (Kölner Phonetik) findet Wörter nach Klangähnlichkeit.

- Wortliste: `oberflaeche/daten/woerter.txt` (wird lokal gepflegt, keine Fremdquelle)

- Gedächtnis: Akzeptierte/Verworfen‑Entscheidungen fließen in lokales Lernen ein (
  Einstellungen → Gedächtnis)

- Regeln lassen sich erweitern; ausführliche Regelhilfen und Beispiele sind in doku/LIESMICH.md.
